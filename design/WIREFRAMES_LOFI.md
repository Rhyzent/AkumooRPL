---

## Design Principles Applied:

1. **Clarity**: Simple hierarchy with clear sections
2. **Consistency**: Repeated layout patterns
3. **Accessibility**: All interactive elements clearly marked
4. **Mobile-First**: Vertical layouts optimized for mobile viewing
5. **Progressive Disclosure**: Information revealed in stages
